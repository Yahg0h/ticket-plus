🎫 Sobre o TicketPlus

Uma plataforma de e-commerce de código aberto para venda de ingressos para eventos

Missão

O TicketPlus foi criado como um projeto de aprendizado para compreender a arquitetura MVC e como trabalhar com aplicações de maior escala organizadas em pastas e módulos. Ele serviu para mim como uma exploração prática da integração de APIs externas, da implementação de melhores práticas de desenvolvimento backend e da criação de algo realmente útil, ainda que simples quando comparado a outras plataformas de produção já existentes.

Visão

O TicketPlus é, no fim das coisas, um projeto de aprendizado, e não uma plataforma comercial. No entanto, eu continuarei a atualizar e a melhorá-lo sempre que o tempo permitir. A base de código dele foi projetada para ser modular e extensível, permitindo que qualquer pessoa faça um fork, modifique e adapte o projeto para seus próprios usos. Seja como um projeto pessoal, um recurso de aprendizado ou a base para algo maior.

Projeto Aberto: Novamente, o TicketPlus não é um produto comercial, é um projeto de aprendizado. Sinta-se à vontade para fazer um fork dele, modificá-lo, alterar sua marca e aparência e até o backend se necessário. Seja mudando ele de nome para "Venda+", "EventHub" ou qualquer outro nome ou adicionar coisas novas que você quer para seu uso dele, você tem total liberdade para isso. O único requisito é respeitar a Licença MIT.

Technology Stack

Backend
  • Python 3.14 — Runtime
  • FastAPI — Framework web
  • SQLAlchemy Core — Abstração de banco de dados
  • MySQL 8.0 — Banco de Dados
  • Uvicorn — Servidor ASGI
Frontend
  • Jinja2 — Template engine
  • Bootstrap 5 — Framework de CSS
  • JavaScript — Interatividade do lado do Client/li>
  • Bootstrap Icons — ícones
Autenticação & Segurança
  • JWT — Autenticação baseada em tokens
  • Argon2 — Password hashing
  • CSRF Protection — Sessão baseada em Tokens
  • Rate Limiting — slowapi
Serviços Externos
  • Stripe — Processamento de pagamento
  • Pillow — Manipulação de imagens
  • ReportLab — Geração de PDFs
  • qrcode — Geração de QR Codes
DevOps & Tools
  • Docker — Conteinerização
  • GitHub Actions — CI/CD
  • Pydantic — Validação de dados
  • python-dotenv — Configurações do ambiente
Dados & Validação
  • validate-docbr — Validação de documentos Brasileiros
  • PyJWT — Codificação e decodificação de JWT
  • aiofiles — Operações de arquivo assíncronoss
